## Sobre o Projeto

<img src="./assets/img/project-desktop-preview.png" alt="project-desktop-preview" width="700">

<br>

O projeto foi desenvolvido seguindo um protótipo fornecido pelo professor, reproduzindo fielmente o layout proposto com HTML semântico e CSS puro, sem frameworks ou dependências externas.

### Principais Features

- Layout responsivo para mobile, tablet e desktop
- Acessibilidade com uso de tags semânticas e atributos alt em imagens
- Navegação por âncoras para as seções principais
- CSS puro com Custom Properties, Flexbox e Grid

### Tecnologias

- HTML5
- CSS3 (Flexbox, Grid, Custom Properties, Media Queries)

## Como Executar

Nenhuma dependência ou instalação necessária. Basta um navegador moderno.

1. Clone o repositório:
   ```bash
   git clone https://github.com/gabrielmoisesa/html-aluguel-iates.git
   ```
2. Acesse a pasta do projeto:
   ```bash
   cd html-aluguel-iates
   ```
3. Abra o arquivo **index.html** no navegador ou use o Live Server no VS Code.
